You are updating the Services-related UI for the Pope Cleaning Services website (Perth, Western Australia).

GOAL
- For specific service text boxes (Residential Cleaning, Vacate / End of Lease, Carpets & Tiles, Office / Commercial), create an animated hover “popup” or popover that shows a small image carousel related to that service.
- When the user hovers with the mouse over the service text area or card, a styled popup should appear with:
  - A short opening animation.
  - A small, realistic image carousel of that specific service.
- The popup must match the existing site style (colors, typography, shadows, animations) and use realistic cleaning images (placeholders for now that we will replace later).

TARGET ELEMENTS
Apply this behaviour to at least these service cards or text boxes:

- Residential Cleaning
- Vacate / End of Lease
- Carpets & Tiles
- Office / Commercial Cleaning

Assume these exist as service cards or items in the Services page or in a summary section (e.g. on Home + Services page). We want the popup to trigger from the SERVICE TEXT AREA (title + short description), not only from the image.

INTERACTION BEHAVIOUR

Desktop:
- When the user hovers the mouse over the service card or the service text area:
  - Show a small “floating” popup near the card (either above, to the side, or overlapping), with a clean animation.
  - The popup contains:
    - A compact heading (the service name).
    - A small image carousel/slideshow with 2–4 realistic images representing that service.
  - The popup should appear with a smooth opening animation:
    - Slight fade-in + scale-up and/or rise-up (e.g. from 95% scale to 100%, from 10–20px below to its final position).
- When the mouse leaves the card/popup area:
  - The popup fades out smoothly.

Mobile / Touch:
- Because hover doesn’t exist on touch devices:
  - Fallback behaviour should be tap-based:
    - Tapping the service card could either:
      - Open a modal overlay with the same image carousel, or
      - Expand a collapsible section below the card showing the images.
  - Ensure mobile behaviour is simple and accessible.

POPUP / POPOVER DESIGN

General style:
- Match the existing brand:
  - Primary blue accents.
  - Rounded corners.
  - Soft shadow to indicate elevation.
  - White/light background inside the popup.
- The popup should feel like a premium “preview” bubble, not a large modal.

Layout inside the popup:
- Small title:
  - E.g. “Residential Cleaning Gallery”
- Image carousel:
  - 2–4 slides per service.
  - Use realistic cleaning images (we will swap them later):
    - Residential: real photos of tidy living rooms, kitchens, bathrooms being cleaned.
    - Vacate / End of Lease: empty or nearly empty rentals, sparkling kitchens/bathrooms.
    - Carpets & Tiles: close-ups of carpet cleaning and tile/grout cleaning.
    - Office / Commercial: offices, desks, meeting rooms, shared spaces being cleaned.
  - Provide descriptive alt text and semantic filenames, for example:
    - `/assets/services/residential-preview-1.jpg`
    - `/assets/services/vacate-preview-1.jpg`
    - `/assets/services/carpets-tiles-preview-1.jpg`
    - `/assets/services/office-preview-1.jpg`
  - Use a simple carousel implementation:
    - Arrows or dots for navigation.
    - Autoplay optional but not required; keep it manual for more control.

ANIMATION REQUIREMENTS

Trigger:
- On hover (desktop), on tap (mobile fallback).

Popup animation:
- Use CSS transforms + opacity for smooth performance:
  - Initial (hidden) state:
    - `opacity: 0`
    - `transform: translateY(10px) scale(0.98)`
  - Visible state:
    - `opacity: 1`
    - `transform: translateY(0) scale(1)`
  - Transition:
    - 200–300 ms, ease-out.

Carousel elements:
- Can have subtle fade/slide transitions between slides, but keep them light so performance remains good.

POSITIONING

Desktop:
- Position the popup relative to the hovered card:
  - Ideally above the card or slightly overlapping it.
  - Use smart positioning to avoid going off-screen (e.g. flip to opposite side if too close to viewport edge).

Mobile:
- If you choose a modal:
  - Centered overlay with a darkened background behind it.
- If you choose an expandable panel:
  - Place the panel directly below the tapped service card.

ACCESSIBILITY

- Ensure that popups:
  - Are keyboard-focusable.
  - Can be triggered with keyboard focus (e.g. on focus, show; on blur, hide).
- Provide `aria` attributes where appropriate, e.g. `aria-describedby` or `aria-label`.
- For mobile modal behaviour:
  - Trap focus inside the modal.
  - Provide a close button with clear label (“Close gallery”).

IMPLEMENTATION DETAILS

Code structure:
- Create a reusable `ServicePreviewPopover` component that:
  - Receives props:
    - serviceName
    - images (array of image paths + alt text)
  - Handles:
    - Hover/tap detection.
    - Popup visibility state.
    - Basic positioning relative to the service card.
    - Carousel controls.
- In the Services cards/list:
  - Wrap or attach this component to the text area of each target service:
    - Residential Cleaning
    - Vacate / End of Lease
    - Carpets & Tiles
    - Office / Commercial
- Keep image arrays easy to edit so we can swap AI-generated or real photos later.

Styling:
- Use the same design system (Tailwind classes or CSS modules, depending on the project).
- Maintain consistency in border radius, shadows and spacing with existing cards.
- Ensure the popup width is appropriate:
  - Large enough to clearly show the images.
  - Not so large that it covers most of the screen.

PERFORMANCE & FALLBACKS

- Use only necessary event listeners (mouseenter/mouseleave) and avoid heavy operations.
- Load images efficiently:
  - Use responsive image components if available in the stack.
  - Consider lazy-loading these preview images to avoid slowing initial page load.
- Make sure the site works fine even if JavaScript animations fail: users should still see the main service information and be able to click “Learn More” or “Book Now”.

OUTPUT

- Implement animated preview popovers for the following services:
  - Residential Cleaning
  - Vacate / End of Lease
  - Carpets & Tiles
  - Office / Commercial
- Each popover must:
  - Show an opening animation.
  - Contain a small carousel of realistic service images.
  - Match the website’s visual style.
- All images should be defined as easy-to-replace placeholders so we can later swap them for new content.
