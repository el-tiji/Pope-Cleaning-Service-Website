You are updating the Pope Cleaning Services website.

TASK
Create and apply a consistent button design system across the entire website.

The goal is to make all buttons visually uniform, professional and aligned with the updated navbar button hierarchy.

IMPORTANT SCOPE

* Do NOT redesign the entire website.
* Do NOT change page content unless a button label is clearly inconsistent.
* Do NOT change routes, form logic, booking logic, admin logic, pricing logic or database logic.
* Only update button styling, button hierarchy and reusable button components/classes.
* Apply the updated button system across all pages:

  * Home
  * Services
  * Pricing Info
  * About Us
  * Reviews
  * Book Now / Quote Request
  * Log In
  * Admin pages if they exist
  * Footer CTAs if present

MAIN GOAL
The website should have a unified button system where every button clearly belongs to one of these categories:

1. Primary CTA
   Used for the most important action on a page.

2. Secondary CTA
   Used for supportive actions.

3. Outline / Ghost button
   Used for lower-priority navigation or secondary actions.

4. Form action button
   Used for Continue, Back, Submit and Save actions.

5. Admin action button
   Used inside the admin dashboard for operational actions.

GLOBAL BUTTON DESIGN PRINCIPLES
All buttons should feel:

* rounded;
* clean;
* premium;
* consistent;
* easy to identify;
* accessible;
* not overly flat;
* not overly heavy.

Use:

* border-radius: 999px for pill buttons;
* consistent height;
* consistent padding;
* consistent font weight;
* subtle shadows;
* smooth hover transitions;
* clear focus states.

Suggested global button settings:

* Font weight: 600 or 700.
* Border radius: 999px.
* Transition: all 200ms ease-out.
* Desktop height: 42–48px.
* Small button height: 36–40px.
* Large CTA height: 50–56px.
* Horizontal padding:

  * small: 16–20px;
  * medium: 22–28px;
  * large: 30–36px.

VISUAL HIERARCHY RULE
Each page should have only one dominant primary CTA in a major visual area.

Avoid having too many solid blue buttons competing in the same section.

When several actions appear together:

* Main action: Primary.
* Secondary action: Secondary.
* Optional action: Ghost or text.

ACCESSIBILITY

* Maintain visible keyboard focus.
* Use focus ring:
  `0 0 0 3px rgba(126, 200, 255, 0.55)`
* Ensure contrast passes readable standards.
* Disabled buttons should be visually distinct.
* Loading buttons should show spinner or loading text.
* Buttons must remain keyboard accessible.
* Do not remove semantic `<button>` for form actions.
* Use `<a>` only for navigation links.

MOBILE REQUIREMENTS

* Buttons should have comfortable tap targets.
* Minimum height: 44px.
* Avoid tiny inline buttons on mobile.
* Full-width primary buttons are acceptable in mobile forms.
* Keep spacing between buttons clear.
* If two buttons appear side by side on mobile and feel cramped, stack them.

MICROINTERACTIONS
Use subtle consistent animation:

* Transition duration: 180–220ms.
* Ease-out.
* Small lift on hover.
* No aggressive bounce.
* No large scaling.
* Respect `prefers-reduced-motion`.
