PART 1 – GLOBAL ANIMATION FOUNDATION

1.1 Reuse and extend existing RevealOnScroll
- You already have a `RevealOnScroll` component imported from `"@/components/ui/reveal-on-scroll"`. [file:178]
- Keep it, but:
  - Ensure it uses Intersection Observer (or similar) to add an `is-visible` class when elements enter the viewport.
  - Base animation:
    - Hidden state: `opacity: 0`, `transform: translateY(24px) scale(0.98)`.
    - Visible state: `opacity: 1`, `transform: translateY(0) scale(1)`.
    - Transition: 400–600ms ease-out.
  - Add support for variants via props, e.g.:
    - `variant="rise" | "fade" | "slide-left" | "slide-right" | "zoom"`.
    - `delay` prop to slightly stagger elements.
  - Implement variants only via CSS classes (no heavy JS).

1.2 Create a small animation tokens/config system
- In a central file (e.g. `@/config/animations.ts`), define:
  - Durations (short, base, long)
  - Easing presets
  - Standard transforms for entrance, hover, button presses, etc.
- Use these across the site so everything feels consistent.

1.3 Respect reduced motion
- Honor `prefers-reduced-motion: reduce`:
  - Disable non-essential animations (scroll reveals, parallax, mouse-follow).
  - Show content in its final static position.

3.1 Buttons
- All primary and secondary buttons (using the existing `Button` component) should have:
  - Hover:
    - Slight scale-up (e.g. `scale(1.03)`).
    - Shadow increase.
    - Background lightening or darkening according to brand palette.
  - Active (pressed):
    - Slight scale-down (e.g. `scale(0.97)`).
- Implement via Tailwind or CSS classes in the `Button` component only, so the change is global.

3.2 Service cards and plan cards
- On hover:
  - Slight lift (translateY(-4px)).
  - Slight scale-up (1.02).
  - Soft shadow and subtle border-color accent in brand blue.
  - If an image is present:
    - Gentle image zoom-in (1.05) with `overflow-hidden` container.

3.3 Icons and trust badges
- On hover/focus:
  - A micro “pop” animation (scale 1 → 1.05 → 1).
  - Optional subtle color accent (e.g. blue tint).

Use the Wix hover animations article as conceptual guidance (visual cues on hover, not full redesign). [web:186][web:183]
